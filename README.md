Cadastro de Alunos
Projeto simples para realização de cadastro de alunos utilizando HTML, CSS e JavaScript.

Funcionalidades
Cadastro de alunos
Exibição dos registros cadastrados
Interface simples e intuitiva
Manipulação dinâmica dos dados com JavaScript
Tecnologias Utilizadas
HTML5
CSS3
JavaScript
Estrutura do Projeto
Cadastro-Alunos/
│
├── index.html
├── estilo.css
├── script.js
└── README.md

Como Executar
Clone este repositório:

Shell
git clone https://github.com/HorrificShell/Cadastro-Alunos.git

Entre na pasta do projeto:

Shell
cd Cadastro-Alunos

Abra o arquivo index.html em qualquer navegador.

Objetivo

Este projeto foi desenvolvido para praticar conceitos básicos de desenvolvimento web, incluindo:

Estruturação de páginas com HTML
Estilização com CSS
Manipulação do DOM com JavaScript
Criação de formulários e gerenciamento de dados
